# NBA 2K16 MyTEAM Viewer v1.1.2

This update adds safe Patch 0 and Patch 10 injection support, authoritative ordered TEAMDATA destinations, saved player identity/model sources, the 1992 USA Olympic and Brandon Roy custom cards, and corrected Eastern name-order handling for Yao Ming.

## Manual release assets

- `NBA.2K16.MyTEAM.Viewer.zip` — replace the Viewer asset with this ZIP.
- `NBA.2K16.Card.Studio.zip` — companion Card Studio ZIP rebuilt from the synchronized preset database.
- `SHA256SUMS.txt` — checksums for both ZIPs.

The selected Patch 0 or Patch 10 version is validated against live TEAMDATA before any player write. A mismatched version selection fails closed.
